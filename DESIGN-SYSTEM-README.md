## Key Concepts

### Design Philosophy
This design system embodies:
- **Authenticity**: Reflects Byzantine heritage
- **Timelessness**: Earth tones never feel dated
- **Warmth**: Inviting, human-centered
- **Heritage**: Respects cultural significance
- **Elegance**: Refined without ostentation

### Design Principles
1. ✓ Use terracotta as primary accent
2. ✓ Pair Montserrat headings with Inter body
3. ✓ Maintain warm, inviting palette
4. ✓ Use subtle shadows and textures
5. ✓ Preserve accessibility standards

### Why These Colors?
- **Terracotta**: Warmth, earth, heritage, authenticity
- **Sage Green**: Balance, nature, tradition, calm
- **Charcoal**: Sophistication, stability, grounding
- **Gold**: Luxury, prestige, timelessness

### Why These Fonts?
- **Montserrat**: Personality, hierarchy, modern geometric sans
- **Inter**: Proven readability, optimized for screens
